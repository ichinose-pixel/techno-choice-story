# テクノストラクチャー 選択式家づくりストーリー

夫婦の漫画と2回の選択から、家づくりで大切にしたいことを考える静的Webサイトです。

HTML/CSS/JavaScriptと同梱画像で動作します。`index.html` をHTTPサーバーで開いてください。GitHub Pagesは `main` ブランチの `/ (root)` を指定します。

`config.js` でブランド表示と資料請求・施工事例・相談先を設定できます。現在はパナソニック公式ページへリンクします。フォーム送信や個人情報の収集は行いません。

漫画とCGは参考イメージです。実際の間取り・性能・仕様は地域やプランなどにより異なり、設計時に個別確認が必要です。
